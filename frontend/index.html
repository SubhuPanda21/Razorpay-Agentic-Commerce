THE PROBLEM

Autonomous checkout is where trust quietly breaks.

Give an LLM a payment tool and a prompt, and it decides how much to spend. That works — until the one time it doesn't.

✕ LLM → GATEWAY DIRECTLY agent.decide("buy the ₹24,999 laptop")
// user's limit was ₹20,000
razorpay.charge(24999)
// nothing stopped it
✓ THIS SYSTEM agent.select("laptop")
policy.evaluate(order, cap=20000)
→ rejected: exceeds spending limit
// deterministic. no override possible.

01 · SHOP

Shopping Agent ▾

Turns a request into a product via explicit tools — never touches the DB directly.

02 · GATE

Policy Engine ▾

Hard spending caps and authorization thresholds. No agent can override this.

order > cap → rejected. final. no retry.
03 · SCORE

Risk Agent ▾

Velocity + amount-anomaly scoring. Defense-only: allow, hold, or block.

6 orders / 10min → velocity flagged

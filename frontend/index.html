Six stages, one guarantee: every rupee explainable.

01 · SHOP

Shopping Agent

Turns a natural-language request into a product, via explicit tools — never touches the DB directly.

02 · GATE

Policy Engine

Hard spending caps and authorization thresholds. Deterministic Python — no agent can talk its way past it.

03 · SCORE

Risk Agent

Velocity + amount-anomaly scoring. Strictly defense-only: allow, hold, or block — never an offensive action.

04 · PAY

Gateway

Razorpay test-mode SDK, with a deterministic mock so it's demoable without live keys.

05 · RECOVER

Recovery Agent

Bounded retries with an alternate payment method — a real stopping rule, not infinite retry.

06 · RECONCILE

Finance Agent

Matches expected vs settled amount. Reports honest exceptions instead of hiding them.
